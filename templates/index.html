HOW IT WORKS

From your words to a model output

A lightweight NLP pipeline processes your symptom description locally.

01

Describe

Enter your skin-related symptoms naturally, without needing a medical format.

02

Vectorize

TF-IDF converts the text description into numerical features for the machine learning model.

03

Classify

A multiclass Logistic Regression model identifies the condition category that best matches the input.

04

Inform

The application displays the model output together with general awareness information.

◉

Designed for awareness

This application is a student/research project designed to demonstrate natural language processing, machine learning, and web application integration.

⚡

Lightweight architecture

The application uses a lightweight text classification pipeline that can run locally without requiring a GPU or cloud-based inference.

🔒

Local processing

In local deployment, the symptom request is processed by your Flask application on the same machine rather than requiring an external prediction service.

!

Important medical disclaimer

Dermaizor is an educational and awareness tool. Its predictions are generated by a machine learning model trained on a project dataset and are not a substitute for professional medical examination, diagnosis, or treatment.

Do not use this application to make urgent medical decisions. Consult a qualified healthcare professional for personal medical advice.
